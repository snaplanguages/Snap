1. Động từ "To Be"

[cite: 2]
Cấu trúc Quá Khứ (Past) Hiện Tại (Present) Tương Lai (Future)
(+) Khẳng định S + Tobe + N/Adj [cite: 2] I/He/She/It + was
You/We/They + were 		I + am
He/She/It + is
You/We/They + are 		Tất cả chủ ngữ + will be
(-) Phủ định S + Tobe + NOT [cite: 2] was not = wasn't
were not = weren't 		am not
is not = isn't
are not = aren't 		will not be = won't be
(?) Nghi vấn Tobe + S + N/Adj? [cite: 2] Was / Were + S...? Am / Is / Are + S...? Will + S + be...?

2. Động từ "Thường" (Action Verbs)

[cite: 2]
Cấu trúc Quá Khứ (Past) Hiện Tại (Present) Tương Lai (Future)
(+) Khẳng định S + Verb [cite: 2] S + V-ed / V2 I/You/We/They + V (nguyên thể)
He/She/It + V-s/es 		S + will + V
(-) Phủ định S + Trợ ĐT + NOT + V [cite: 2] Did not = Didn't + V Do not = Don't + V
Does not = Doesn't + V 		Will not = Won't + V
(?) Nghi vấn Trợ ĐT + S + V? [cite: 2] Did + S + V? Do / Does + S + V? Will + S + V?
